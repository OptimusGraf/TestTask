Тестовое задание
Это консольное приложение на C#, реализующее справочник сотрудников с хранением данных в базе SQLite.
Для взаимодействия с базой данных используется библиотека ADO.NET (Microsoft.Data.Sqlite).

Приложение демонстрирует применение объектно-ориентированного подхода, работу с базой данных через интерфейс, генерацию большого объёма данных, пакетные вставки (batch insert) и оптимизацию запросов с использованием индексов.

⚙️ Основные возможности (режимы работы)

1. Создание таблицы
Создание таблицы Employees с полями:
Name (Фамилия Имя Отчество)
BirthDate (дата рождения)
Sex (пол)

2. Добавление записи
Добавление одной записи в базу данных через консоль.


3. Вывод записей
Отображение всех уникальных сотрудников с расчётом возраста и сортировкой по ФИО.

4. Генерация данных
Автоматическая генерация 1 000 000 случайных записей и 100 записей, где фамилия начинается с «F» и пол — мужской.
Используется пакетная вставка (InsertManyEmployees) с транзакциями для повышения производительности.

5. Выборка с фильтрацией и замером времени
Запрос выборки сотрудников мужского пола, чья фамилия начинается с буквы «F».
Производится замер времени выполнения запроса.

6. Оптимизация
Добавляется вспомогательный столбец FirstLetter и создаётся индекс (FirstLetter, SEX), что ускоряет выборку

🧩 Архитектура

Employee — класс, представляющий сотрудника. Содержит свойства Name, Sex, BirthDate и вычисляемое свойство Age.

IDataBase — интерфейс для взаимодействия с базой данных, определяющий методы CRUD и выборки.

DataBaseSqlite — реализация интерфейса IDataBase на основе ADO.NET. Использует SqliteConnection, SqliteCommand, SqliteParameter и транзакции (BeginTransaction).

ООП-принципы — инкапсуляция логики доступа к данным, абстракция через интерфейс, модульность и возможность замены реализации БД.
